
# R Data Science Lab

A collection of projects developed in R for practicing data science, data analysis, visualization, machine learning, and fundamental data engineering workflows.

Each directory contains an independent project built around real-world data.

## Projects

### COVID-19 Analysis — Brazil

Analysis of COVID-19 data in Brazil using data from Our World in Data.

The project explores cases, deaths, vaccination, and temporal trends using data transformation and visualization techniques.

**Topics:** data analysis, time series, visualization, reproducible reporting

---

### Finance Dashboard

Interactive dashboard for exploring personal finance data.

The application provides dynamic filters, summary statistics, interactive charts, and tabular visualization using Shiny.

**Topics:** data visualization, dashboards, interactive analytics

---

### Brazilian Public Data

Data pipeline and analytical project combining Brazilian socioeconomic and educational data from multiple public sources.

The project includes:

- Data acquisition from public data sources using R packages and APIs
- Separation of data into `raw` and `processed` layers
- Cleaning and standardization of heterogeneous datasets
- Normalization of state identifiers and geographic information
- Integration of datasets from different sources
- Construction of an **Analysis Base Table (ABT)** at the Brazilian state level
- Statistical and geospatial analysis
- Interactive visualization and reproducible reporting

The resulting ABT consolidates indicators such as:

- IDEB score
- Human Development Index
- Literacy rate
- Income per capita
- Population

This processed dataset acts as the analytical source for downstream statistical analysis, visualizations, maps, and reports.

**Topics:** data engineering, data integration, ETL, analytical datasets, public data, geospatial analysis

---

### Student Grade Prediction

Project exploring student performance data and predictive modeling in R.

The project combines exploratory data analysis with statistical and machine learning techniques for grade prediction.

**Topics:** exploratory data analysis, statistical modeling, machine learning
