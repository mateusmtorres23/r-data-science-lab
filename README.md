# R Data Science Lab

A collection of data science projects developed in R for practicing data analysis, visualization, statistical exploration, machine learning, and interactive reporting.

Each directory contains an independent project built around a real-world dataset.

## Projects

### COVID-19 Analysis — Brazil

Analysis of COVID-19 data in Brazil using data from Our World in Data.

The project explores cases, deaths, vaccination, and temporal trends using data transformation and visualization techniques.

**Technologies:** tidyverse, ggplot2, lubridate, R Markdown

### Finance Dashboard

Interactive dashboard for exploring personal finance data.

The application provides filters, summary statistics, interactive charts, and tabular visualization.

**Technologies:** Shiny, Plotly, DT, dplyr, ggplot2, bslib

### Brazilian Public Data

Analysis of Brazilian public datasets involving data acquisition, cleaning, exploratory analysis, visualization, and reproducible reporting.

**Technologies:** dplyr, tidyr, ggplot2, R Markdown

### Student Grade Prediction

Project exploring student performance data and predictive modeling in R.

The project combines exploratory data analysis with statistical and machine learning techniques for grade prediction.

## Topics

- Data cleaning and transformation
- Exploratory Data Analysis
- Data visualization
- Statistical analysis
- Machine learning
- Interactive dashboards
- Reproducible reports
